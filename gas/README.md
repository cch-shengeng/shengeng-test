# 課程現場簽到・簽退・滿意度

```
手機掃 QR Code（縮網址）→ GitHub 網頁 /checkin/ /checkout/ /feedback/
                                   ↓ 送出
                    Google Apps Script（本資料夾 Code.gs）
                                   ↓ 寫入
             Google 試算表「深耕課程簽到系統」（不公開）
```

| 縮網址 | 指向的 GitHub 網頁 |
|---|---|
| https://cchedu.pse.is/update-in | https://cch-shengeng.github.io/shengeng/checkin/ |
| https://cchedu.pse.is/update-out | https://cch-shengeng.github.io/shengeng/checkout/ |
| https://cchedu.pse.is/update-feedback | https://cch-shengeng.github.io/shengeng/feedback/ |
| 管理頁（不對外） | https://cch-shengeng.github.io/shengeng/attend/admin.html |

縮網址只要設定一次。之後每次辦活動，只改試算表的「活動設定」。

---

## 一、第一次設定（約 20 分鐘）

> ⚠️ 請**另外開一份新的試算表**，不要用網站後台那份。網站後台那份是「知道連結的任何人可檢視」，簽到資料有個人資料，必須放在不公開的試算表。

1. **建立試算表**：到 Google 雲端硬碟 → 新增 → Google 試算表，命名「深耕課程簽到系統」。建議用部門共用帳號建立，換承辦人時比較好交接。
2. **貼上程式**：上方選單「擴充功能」→「Apps Script」。刪掉預設的 `function myFunction() {}`，把 `Code.gs` 全部內容貼上，按儲存（磁碟片圖示）。
3. **建立分頁**：上方函式選單選 `setup` → 按「執行」。
   - 第一次會要求授權：選你的帳號 → 若出現「Google 尚未驗證這個應用程式」，按「進階」→「前往（不安全）」→「允許」。這是因為程式是你自己寫的，不是公開上架的 App。
   - 完成後試算表會多出四個分頁：**活動設定、問卷題目、簽到紀錄、滿意度**。
4. **設定管理頁密碼**：Apps Script 左側齒輪「專案設定」→ 最下方「指令碼屬性」→「新增指令碼屬性」
   - 屬性：`ADMIN_KEY`
   - 值：自訂一組密碼（建議 10 字以上）→ 儲存
5. **部署**：右上角「部署」→「新增部署作業」→ 齒輪選「網頁應用程式」
   - 說明：深耕簽到
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 按「部署」→ 複製「網頁應用程式網址」（`https://script.google.com/macros/s/……/exec`）
6. **接上網站**：在 GitHub 打開 `attend/attend-config.js` → 鉛筆編輯 → 把網址貼到 `gasUrl: ''` 的引號中間 → Commit changes。
7. **改縮網址**：到 PicSee（pse.is）後台，把三個縮網址的目的網址改成上表的 GitHub 網頁。

## 二、測試（設定完一定要做）

1. 「活動設定」第 2 列已有一筆 12/9 範例，**「測試模式」已勾選**（不限時間開放）。
2. 用手機掃縮網址：簽到 → 簽退 → 填問卷，各試一次。
3. 打開管理頁，輸入 `ADMIN_KEY` 密碼，確認看得到剛剛的測試資料。
4. 測試完：到「簽到紀錄」「滿意度」分頁**刪除測試資料列**（保留第 1 列標題）。
5. 上課前：把「測試模式」**取消勾選**。

## 三、每次辦活動要做的事

在「活動設定」新增一列（或修改現有那列），把這場的「啟用」打勾，其他場取消勾選：

| 欄位 | 說明 |
|---|---|
| 啟用 | 打勾 = 縮網址會顯示這場。同時只勾一場 |
| 活動代號 | 每場不同即可，例如 `20261209-與時俱進`。用來區分各場資料，**活動開始後不要再改** |
| 課程名稱、日期、開始、結束、地點、講師 | 顯示在簽到頁上。日期寫 `2026/12/09`，時間寫 `12:20` |
| 簽到開放／簽到截止 | 留空 = 開始前 60 分鐘開放，到結束時間截止 |
| 簽退開放／簽退截止 | 留空 = 結束前 30 分鐘開放，到結束後 2 小時截止 |
| 報名表連結 | 簽到頁底部會顯示「還沒報名？前往報名表」 |
| 現場代碼 | 選填。填了之後要輸入代碼才能簽到簽退，防止不在現場的人遠端簽到。可把代碼加在 QR Code 網址後面：`…/checkin/?c=代碼`，掃碼的人就不用手動輸入 |
| 機構選項 | 選填，用逗號分隔，例如 `彰化基督教醫院,部立南投醫院,其他`。留空 = 彰基、部立南投、南基、埔基、其他 |
| 測試模式 | 打勾 = 不限時間開放，只在測試時用 |

滿意度問卷：課程當天開始後到結束後 7 天內都可以填。

## 四、問卷題目

「問卷題目」分頁一列一題：

| 欄位 | 說明 |
|---|---|
| 啟用 | 取消勾選就不顯示 |
| 題號 | 決定顯示順序 |
| 題目 | 題目文字。同一題目會寫到「滿意度」分頁的同一欄 |
| 類型 | `量表`（1～5 分）、`單選`、`複選`、`文字` |
| 選項 | 單選、複選才需要，用逗號分隔 |
| 必填 | 打勾 = 必填 |
| 適用活動 | 留空 = 所有活動都用；填活動代號 = 只有那幾場出現（多個用逗號分隔） |

## 五、規則說明

- 簽到以「姓名＋服務機構」辨識同一個人。重複簽到不會重複寫入，會顯示原本的簽到時間。
- 必須先簽到才能簽退和填問卷。查不到時，請對方確認姓名和機構與簽到時一致。
- 同一支手機會記住填過的姓名、機構，簽退和填問卷時自動帶入。
- 管理頁每 30 秒自動更新；可下載 CSV、列印 QR Code。完整資料都在試算表裡。

## 修改 Code.gs 之後

**部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署**。網址不變，改動才會生效。
若誤按「新增部署作業」會產生新網址，就要再更新 `attend/attend-config.js` 的 `gasUrl`。
