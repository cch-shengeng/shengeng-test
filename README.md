# 彰基教學部深耕計畫專區（GitHub Pages 版）

單頁式網站，內容由一份 **Google 試算表** 維護。同仁在試算表加一列、勾選「刊登」，網站重新整理就會更新，不需要改程式。

## 檔案結構

```
index.html      網頁本體（版面、固定文字）
style.css       樣式（顏色、字型、版面）
app.js          讀取資料、產生課程列表等畫面
config.js       設定檔：Google 試算表 ID、原系統連結
data.js         內建備援資料（試算表讀不到時使用）
data/*.csv      五個分頁的範例資料（也就是 data.js 的來源）
cms.json        從醫院網頁自動同步來的「成果」「議錄」（排程自動更新，請勿手動改）
scripts/sync_cms.py               自動同步程式
.github/workflows/sync-cms.yml    自動排程設定（每天 07:23、12:53）
assets/         Logo、水彩插畫、院區照片
深耕專區_網站後台試算表範本.xlsx   後台試算表範本（上傳到 Google 雲端硬碟用）
```

## 一、第一次上線（約 15 分鐘）

1. **建立 GitHub 程式庫**：在 GitHub 新增一個 Public repository，把本資料夾所有檔案上傳。
2. **開啟 GitHub Pages**：Settings → Pages → Branch 選 `main`、資料夾 `/ (root)` → Save。1～2 分鐘後就會出現網址（例如 `https://帳號.github.io/專案名/`）。
3. **建立後台試算表**：
   - 把 `深耕專區_網站後台試算表範本.xlsx` 上傳到 Google 雲端硬碟，按右鍵 →「選擇開啟工具」→ Google 試算表，再按「檔案 → 儲存為 Google 試算表」。
   - 右上角「共用」→ 一般存取權改成「**知道連結的任何人**」＋「檢視者」。（網站要能讀取，必須設定這一步；編輯權限只開給負責同仁。）
4. **連接網站**：複製試算表網址中 `/d/` 和 `/edit` 之間那一長串 ID，貼到 `config.js` 的 `sheetId: ''` 引號中間，存檔上傳。
5. 打開網站，頁尾顯示「資料來源：Google 試算表」即表示成功。

## 二、日常維護（只動試算表）

| 分頁 | 用途 | 出現在網頁的位置 |
|---|---|---|
| 公告 | 一句話公告 | 首屏下方綠色跑馬燈 |
| 課程 | 課程與活動 | 「課程報名」區，以及首屏「下一堂課」卡片 |
| 成果 | 計畫成果分享 | 「精選」打勾者 → 成果亮點大卡片（最多 3 則）；全部 → 成果列表 |
| 議錄 | 工作討論會議清單 | 成果列表右側 |
| 資源 | 數位學習、教學資源、往期課程連結 | 「教學資源」區，依「分類」欄自動分組 |

**共同規則**

- 新增一則 = 新增一列。順序不重要，網站會依日期自動排序。
- 「刊登」選 `FALSE` 就會先隱藏，不必刪除。
- 日期請寫 `2026/11/04`（民國 `115/11/04` 也可以）；時間寫 `13:30`。範本已把這些欄設成純文字，避免 Google 自動轉格式。
- 連結欄請貼完整網址（`https://` 開頭）。

**課程狀態是自動算的**，不用手動改：

| 狀態 | 條件 |
|---|---|
| 報名中 | 尚未開課，且未過報名截止日 |
| 即將截止 | 距報名截止 7 天內 |
| 報名已截止 | 已過報名截止日，尚未開課 |
| 報名待公告 | 「報名方式」寫「待公告」，或寫「線上表單」但還沒填報名連結 |
| 已結束 | 上課日已過 |

「報名方式」寫「洽合作醫院窗口」且沒有報名連結時，按鈕會連到原系統的「各指標業務窗口聯絡資訊」。每一堂未結束的課也會有「加入 Google 行事曆」連結。

**圖片怎麼放？**（成果的「圖片連結」欄）

- 已上傳到醫院原系統的照片：在原系統文章中對照片按右鍵 →「複製圖片網址」，貼上即可。
- 放在 Google 雲端硬碟：檔案共用設成「知道連結的任何人」，取得檔案 ID 後填成 `https://drive.google.com/thumbnail?id=檔案ID&sz=w1600`。
- 沒有圖片時留空，網站會改用院區照片或水彩插畫。

## 三、注意事項

- **公開性**：GitHub 免費版的程式庫是公開的；試算表也必須設成「知道連結即可檢視」。內部資料（例如會議紀錄全文）請留在醫院原系統，網站只放標題與連結。
- **更新延遲**：試算表修改後，網站重新整理即可看到，通常幾秒到 1 分鐘。
- **備援**：試算表若讀不到（例如誤改了共用設定），網站會自動顯示 `data.js` 的內建資料，頁尾會出現提示。
- **改分頁名稱或欄位名稱**：分頁名稱要和 `config.js` 的 `tabs` 一致；欄位（第一列）名稱請不要更改，可以在最右邊新增自己用的欄位，網站會忽略。
- **報名資料**：GitHub 只負責顯示，報名仍由 Google 表單／Microsoft Forms 收件。

## 四、醫院網頁自動同步（成果、議錄、數位學習、多元教學資源、課程清單）

GitHub 每天兩次（台灣時間 07:23、12:53）會自動讀取醫院部門網頁的「計畫成果分享」「工作討論議錄」列表，
抓下標題、日期、連結和文章第一張照片，存成 `cms.json`。網頁會把它和試算表的「成果」「議錄」分頁合併顯示：

- **在醫院網頁發文即可**，不用再到試算表補一列。
- 試算表裡有同一篇（「文章連結」相同）時，以試算表填的欄位為準：可以用來改摘要、換照片、設「精選」或用「刊登 = FALSE」隱藏。
- 成果亮點大卡片：先放「精選」打勾的，不足 3 則時，自動補上最新且有照片的文章。想完全自動，就把試算表「精選」欄全部清空。
- 想立刻同步：GitHub → **Actions** → 左側「同步醫院網頁成果與議錄」→ **Run workflow**。
- 排程失敗（紅色叉叉）時 GitHub 會寄信通知，網站會繼續顯示上一次成功同步的內容。最常見原因是醫院網頁改版，需要調整 `scripts/sync_cms.py` 最上方的設定。

### 同步範圍

| 醫院網頁 | 網站顯示位置 | 和試算表的關係 |
|---|---|---|
| 計畫成果分享（cID=610） | 成果亮點、成果列表 | 試算表同一篇有填的欄位會**覆蓋** |
| 工作討論議錄（cID=611） | 議錄列表 | 同上 |
| 數位學習與服務（cID=609） | 教學資源 › 數位學習與服務 | 試算表「資源」分頁同分類、名稱相近的以試算表為準 |
| 多元教學資源（cID=612） | 教學資源 › 多元教學資源 | 同上；目前沒有文章也不會報錯 |
| 課程活動訊息 › 最新兩季課程清單（cID=1349） | 課程報名 | **以醫院網頁為準**；試算表同一堂課（同日期、名稱相近）只補空白欄位，例如類別、適用對象、報名截止；「刊登 = FALSE」可隱藏 |

課程清單的讀法：表格欄位「日期及時間｜課程名稱｜課程地點｜附件｜報名｜備註」。
「附件」中的「活動海報」「簡章」、「報名」中的報名網址會自動帶入；備註寫「報名截止日115/12/23」或「10/22前報名」會自動當作報名截止日。
醫院網頁沒有公告的活動（例如內部參訪），照常在試算表「課程」分頁新增即可。
想多放一個議程表按鈕：在試算表「課程」分頁最右邊新增一欄「議程連結」。
